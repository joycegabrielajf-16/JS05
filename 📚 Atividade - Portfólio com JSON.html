📚 Atividade: Portfólio com Dados em JSON

Crie seu portfólio pessoal utilizando HTML, CSS, JavaScript e um arquivo JSON

📝 1 arquivo HTML 📄 1 arquivo JSON 📁 1 pasta de ícones 🚀 GitHub Pages 📋 15 questões

🎯 Objetivo da Atividade

💡 Por que fazer isso? Nesta atividade você vai aprender a:
  • ✅ Organizar um projeto web com pastas e arquivos
  • ✅ Utilizar JSON para armazenar dados (conhecimentos e projetos)
  • ✅ Aplicar laços de repetição (for, forEach) para exibir dados
  • ✅ Usar condicionais (if/else) para tratar situações diferentes
  • ✅ Consumir dados com fetch() e promises
  • ✅ Publicar seu portfólio no GitHub Pages
📌 Importante: Você deve criar seu próprio arquivo data.json com seus dados pessoais, conhecimentos e projetos.

📁 Estrutura de Pastas do Projeto

Seu projeto deve ter a seguinte organização:

📁 meu-portfolio/
│
├── 📄 index.html ← Página principal (código completo abaixo)
├── 📄 data.json ← Seus dados (personalize!)
│
└── 📁 icons/ ← Pasta com os ícones SVG
    ├── 📄 html5.svg
    ├── 📄 css3.svg
    ├── 📄 javascript.svg
    ├── 📄 git.svg
    ├── 📄 github.svg
    └── 📄 vscode.svg
✅ Dica: Você pode criar outros ícones para suas tecnologias! Procure por "SVG icons free" no Google.

🚀 Como publicar no GitHub Pages

📌 GitHub Pages é um serviço gratuito que hospeda páginas estáticas diretamente do seu repositório. Perfeito para portfólios!

Passo 1: Crie um repositório no GitHub

  • Acesse github.com/new
  • Dê um nome para o repositório (ex: meu-portfolio)
  • Deixe como Público (para o GitHub Pages funcionar)
  • Clique em "Create repository"

Passo 2: Faça upload dos arquivos

  • Na página do repositório, clique em "Add file" → "Upload files"
  • Arraste os arquivos:
    • index.html
    • data.json
    • A pasta icons/ (com todos os SVG)
  • Escreva uma mensagem de commit (ex: "Adicionando portfólio")
  • Clique em "Commit changes"

Passo 3: Ative o GitHub Pages

  • No repositório, clique em "Settings" (no menu superior)
  • No menu lateral esquerdo, clique em "Pages"
  • Na seção "Branch", altere a caixa de seleção de "None" para "main"
  • Clique no botão "Save"
  • Aguarde alguns minutos (pode levar até 2-3 minutos para publicar)
✅ Pronto! Seu portfólio estará disponível em:
https://seu-usuario.github.io/nome-do-repositorio/

Passo 4: Teste em outros dispositivos

  • 📱 Abra o link no seu celular
  • 💻 Abra em outro computador
  • 🖥️ Teste em diferentes navegadores (Chrome, Firefox, Edge)
  • 📏 Verifique se o layout está responsivo (se adapta à tela)
