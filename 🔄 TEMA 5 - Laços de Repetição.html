Laços de Repetição em JavaScript

🔄 O que são Laços de Repetição?

💡 Analogia: Laços de repetição são como tarefas repetitivas do dia a dia. Por exemplo: "Enquanto houver alunos na fila, chame um por um". Na programação, usamos laços para executar um bloco de código várias vezes.

Os laços de repetição (ou loops) são estruturas que permitem executar um bloco de código repetidamente enquanto uma condição for verdadeira. Eles são fundamentais para automatizar tarefas repetitivas, como processar listas de itens, fazer validações e manipular dados.

📌 Exemplo do dia a dia: "Contar de 0 a 10" — isso é uma repetição! Um loop faz exatamente isso: repete uma ação um número determinado de vezes.

Fluxograma: loop while verificando se i é menor que 11

Em JavaScript, os principais laços de repetição são: for, while e do...while. Cada um tem suas características e é mais adequado para diferentes situações.

📝 Tipos de Laços de Repetição

Tipo Descrição Exemplo
for Usado quando sabemos o número exato de repetições. for (let i = 0; i < 10; i++) { ... }
while Verifica a condição antes de executar o bloco. while (condição) { ... }
do...while Executa o bloco pelo menos uma vez, depois verifica a condição. do { ... } while (condição);
for...in Itera sobre as propriedades de um objeto. for (let chave in objeto) { ... }
for...of Itera sobre valores de coleções iteráveis (arrays, strings, etc). for (let valor of array) { ... }

📌 Laço FOR (contador de 0 a 10)

📄 for.js
// Laço FOR - Contagem de 0 a 10 for (let i = 0; i < 11; i++) { console.log(i); }
✅ Copiado!

📌 Laço WHILE (contador de 0 a 10)

📄 while.js
// Laço WHILE - Contagem de 0 a 10 let i = 0; while (i < 11) { console.log(i); i++; }
✅ Copiado!

📌 Laço DO...WHILE (contador de 0 a 10)

📄 do-while.js
// Laço DO...WHILE - Contagem de 0 a 10 let i = 0; do { console.log(i); i++; } while (i < 11);
✅ Copiado!

📌 Laço FOR...OF (iterando sobre um array)

📄 for-of.js
// Laço FOR...OF - Iterando sobre um array let frutas = ["Maçã", "Banana", "Laranja"]; for (let fruta of frutas) { console.log(fruta); }
✅ Copiado!

📌 Laço FOR...IN (iterando sobre um objeto)

📄 for-in.js
// Laço FOR...IN - Iterando sobre um objeto let pessoa = { nome: "João", idade: 25, cidade: "São Paulo" }; for (let chave in pessoa) { console.log(chave + ": " + pessoa[chave]); }
✅ Copiado!

📌 Usando BREAK para interromper um laço

📄 break.js
// Usando BREAK para interromper o laço for (let i = 0; i < 10; i++) { if (i === 5) { break; // Interrompe o loop quando i for igual a 5 } console.log(i); }
✅ Copiado!
⚠️ ATENÇÃO: Evite loops infinitos! Sempre garanta que a condição do loop se torne falsa em algum momento.

🎯 Resumo dos Laços de Repetição

🔹 for

Usado quando sabemos o número exato de repetições.

for (inicialização; condição; incremento) {
  // ações
}

🔹 while

Verifica a condição antes de executar o bloco.

while (condição) {
  // ações
}

🔹 do...while

Executa o bloco pelo menos uma vez, depois verifica a condição.

do {
  // ações
} while (condição);

🔹 for...in / for...of

for...in: itera sobre chaves de objetos.
for...of: itera sobre valores de coleções.

for (chave in obj) { ... }
for (valor of array) { ... }
