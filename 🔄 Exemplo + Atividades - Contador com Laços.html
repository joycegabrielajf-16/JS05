// EXEMPLO PRÁTICO DA CONEXÃO <input type="number" id="valorContagem"> ← HTML: input com ID valorContagem <div id="resultado"></div> ← HTML: div com ID resultado <button onclick="contarFor()">Contar com FOR</button> ← HTML: botão chama função JS #resultado { background: #f0f0f0; } ← CSS: estiliza #resultado let valor = document.getElementById("valorContagem").value; ← JS: lê o valor do input let resultado = document.getElementById("resultado"); ← JS: busca o elemento for (let i = 0; i <= valor; i++) { resultado.textContent += i + "\n"; } ← JS: loop for que conta de 0 até o valor
💡 O ID é a chave! O id="valorContagem" e id="resultado" no HTML conectam com o JS via getElementById(). O JS executa os laços e exibe o resultado.

📊 Fluxo dos Laços de Repetição

FOR (inicialização; condição; incremento) → repete N vezes
WHILE (condição) { ... } → repete enquanto condição for verdadeira
DO...WHILE { ... } while (condição) → executa pelo menos uma vez
💡 Como funciona: Os três laços fazem a mesma coisa (contar de 0 até N), mas com sintaxes diferentes. O for é usado quando sabemos o número de repetições, o while quando não sabemos, e o do...while quando precisamos executar pelo menos uma vez.
