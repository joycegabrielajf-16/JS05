4 Iterando sobre um Array (FOR...OF)

📌 Enunciado:

Dado o array let cores = ["Vermelho", "Verde", "Azul", "Amarelo"];

Use o laço for...of para exibir cada cor em uma linha separada.

💡 Dica: A estrutura do for...of é: for (let cor of cores) { console.log(cor); }
🔗 Link útil:
// Iterando sobre um array com FOR...OF let cores = ["Vermelho", "Verde", "Azul", "Amarelo"]; for (let cor of cores) { console.log(cor); }

5 Interrompendo um Loop com BREAK

📌 Enunciado:

Use o laço for para contar de 0 a 10, mas interrompa a execução quando chegar em 5 usando break.

Exiba apenas os números de 0 a 4.

💡 Dica: Use if (i === 5) { break; } para interromper o loop. for (let i = 0; i <= 10; i++) {
  if (i === 5) { break; }
  console.log(i);
}
🔗 Link útil:
// Interrompendo o loop com BREAK for (let i = 0; i <= 10; i++) { if (i === 5) { break; } console.log(i); }
